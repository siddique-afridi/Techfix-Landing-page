# 🚀 TechFix – Landing Page

TechFix is a modern, responsive landing page built to represent a **tech repair service** business.  
It showcases services, company info, testimonials, and a contact section in a professional manner.  

---

## 📌 Features
- ✅ Modern UI with HTML5 & CSS3
- ✅ Clean grid & flexbox layouts
- ✅ Contact section with email & phone info
- ✅ Social media integration with Font Awesome icons
- ✅ Footer with quick links and copyright

---

## 🛠️ Tech Stack
- **HTML5** – structure  
- **CSS3** – styling and responsiveness  
- **javascript** - limit check for textarea
- **Font Awesome** – icons  

---

## 📂 Project Structure
TechFix/
│── index.html # Main landing page
│── style.css # Stylesheet
│── index.js # JavaScript (interactivity & functionality)
